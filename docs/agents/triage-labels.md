# Triage labels

Configured status for approved local implementation tickets:

| Role | Local status |
| --- | --- |
| Agent-ready work | ready-for-agent |

The user approved the ticket breakdown and then chose a local-only tracker.
Write this status into each ticket; do not create or apply GitHub labels.
Other triage roles are outside this configuration.

This status marks reviewed work suitable for an agent. It does not mean all
blocking issues are done: execution starts only when every blocker is complete.
